# 阶跃 StepFun AI 数据处理与分析岗位 · 一页速览

> 适用对象：用户提供的“离线/实时数仓 + 算法训练数据 + 指标体系”岗位描述，以及所有相近的 LLM 数据平台、预训练数据、评测数据和 Agent 可观测岗位。

## 岗位本质

这不是“把数据搬到仓库里”的工作，而是把不确定、异构、持续变化的数据，变成算法和产品团队可以信任的决策资产。一个合格的候选人既要能处理 PB 级原始资料，也要能解释某次评测为什么跌了 2 分；既要能写 Spark/Flink/SQL/Python，也要能判断“这批样本值不值得加入训练”。

可以用下面的公式记忆岗位产出：

```text
可靠数据资产 = 可追溯来源 × 可复现加工 × 可解释质量 × 可量化收益
```

其中任何一项为零，数据再多也很难转化成模型能力或可靠的产品改进。

## 三条数据闭环

| 数据闭环 | 原始输入 | 关键加工 | 最终要回答的问题 |
|---|---|---|---|
| 训练数据闭环 | 网页、代码、图文、音频、人工标注 | 解析、去重、质量打分、安全过滤、数据配比、版本管理 | “哪些数据值得让模型学习？” |
| 后训练与评测闭环 | 指令样本、偏好对、Agent 轨迹、评测题 | Rubric、标注一致性、分桶、回归比较、bad case 聚类 | “模型能力变化由什么数据变量造成？” |
| 生产 Agent 闭环 | Prompt、推理步骤、工具调用、沙箱、Token、用户反馈 | Trace 采集、会话还原、检索、预聚合、成本与质量分析 | “真实失败发生在哪一步，应该改数据、模型还是 Harness？” |

## 公开信号与推断边界

公开资料可以确认阶跃官网持续强调多模态模型、Agent 工作流和工具调用；官方招聘页可见“LLM 预训练数据算法工程师”等相近职位；SelectDB 技术活动的演讲材料披露了 StepTrace 用于 Agent 可观测的实践，并提到 SWE-Agent 与智能座舱场景。

不能因此推断出其完整训练语料来源、内部数据量级、具体的 Spark/Ray/Flink 选型，或把厂商演讲中的性能数字当成独立审计结论。本案例中的数仓分层、数据湖、流批架构均为“面试建议方案”，不是对阶跃内部系统的断言。

## 面试能力权重

| 能力 | 建议权重 | 面试官期待的不是 | 面试官真正想听的 |
|---|---:|---|---|
| 数据判断力 | 30% | 会背一堆过滤规则 | 能把质量、覆盖、风险、成本和模型收益连成闭环 |
| Python / SQL / 分布式工程 | 25% | 只会 pandas 或普通 SQL | 能将规则与统计变成可扩展、可回放、可观测的 pipeline |
| LLM 数据链路理解 | 20% | 会解释名词 | 清楚预训练、SFT、偏好、RL、评测分别优化什么，不能互相替代什么 |
| 分析与实验设计 | 15% | 做一张看板 | 能控制变量、切分数据、分析显著性，并避免基准集污染 |
| 跨团队 Owner 意识 | 10% | “等算法给需求” | 将算法目标翻译为数据验收标准，并主动推动交付、复盘和版本化 |

## 最值得准备的五个回答

第一，给一批爬取网页，如何从原始 WARC/HTML 走到可训练数据集，并如何保留来源、许可证、处理版本和删除理由。

第二，SFT 数据与偏好数据质量分别如何衡量。SFT 关注指令清晰度、答案正确性、任务覆盖和格式一致性；偏好数据还必须关注成对可比性、偏好理由、标注一致性与长度偏差。

第三，某项评测下降 2 分时，如何区分统计波动、评测污染、数据版本变化、推理参数变化、模型回归和工具链故障。

第四，如何为 Agent Trace 建模，使其既支持单条失败回放，也支持会话、版本、成本、延迟、工具成功率等多维聚合。

第五，如何证明一条数据清洗或合成规则“真的有益”。答案不能是“跑完数据更干净了”，而应该是冻结基线、构建受控数据版本、在隔离评测集上做消融，并同时看能力、安全、成本与退化桶。

## 公开的 StepTrace 实践，能带来的三个启示

公开技术分享提到，StepTrace 需要处理 prompt、reasoning、tool call 等 Agent 特有字段，支持 session 级复盘、Token 成本分析、文本与元数据检索、评测闭环，以及与沙箱、KV Cache、调度等基础设施关联。其数据底座诉求包括宽表、半结构化 JSON、全文检索、多维 Rollup 和在线/离线混合负载治理。

这说明“AI 数据分析”不只发生在训练前。对于 Agent 产品，生产运行轨迹本身会成为下一轮评测、SFT、RL 和 Harness 优化的候选数据资产；但它必须经过隐私脱敏、质量筛选、目标定义和人工/自动审核，绝不能把线上轨迹不加处理地回灌训练。
