# 10.5 面试准备路径与高频问题

准备优先级：P0 是 KMS 生命周期、信封加密、HSM/PKI、SM2/SM3/SM4 与租户授权审计；P1 是异地容灾、密钥轮换、SDK、密评证据链；P2 是 QKD、可信中继、密钥池和调度；Java 并发、数据库和微服务作为实现基础复习。

**如何设计多租户 KMS？** 回答应覆盖：Key 与 Policy 强制绑定 tenant_id；身份令牌解析租户上下文；授权同时判断主体、操作、资源和用途；缓存/MQ/对象路径都隔离；Decrypt/Sign 强审计；关键租户使用独立 HSM 分区或独立部署；不能只靠 SQL 的 tenant_id 过滤。

**为什么要信封加密？** DEK 加密业务数据，KEK 包裹 DEK，MK 留在 HSM。它使数据面加密不依赖远程 KMS 的每字节吞吐，也使 KEK 轮换只重包 DEK；需要保存密钥版本以读取历史密文。

**密钥轮换如何不中断？** 新写入使用新版本；旧版本保持 decrypt/verify 权限直到历史密文迁移或保留期结束；密文携带 key version；轮换操作幂等、可观测、可回滚到“停止激活新版本”而非删除旧版本。

**量子密钥调度要考虑什么？** 除路径长度外，还看链路密钥池余量和生成率、QoS、可信节点、预留与释放、失败重试幂等、跨域审计。QKD 提供密钥，不是业务数据传输协议。
