# 10.1 岗位拆解与知识映射

岗位可分为四条产品线。KMS 方向以 Java 和密钥管理为核心，要求国密/密评、异地多活、分库分表；CMSP 方向关注分布式架构、多线程高并发与数据库性能；KAAS 方向要求数据治理、多租户隔离和服务切片；量子网络方向以 Go、密钥调度、SDK、密钥中继与存储为核心。

| 要求 | 现有覆盖 | 结论 |
|---|---|---|
| Java、并发、数据库、分库分表 | 第三章 3.1、3.9、3.13 | 已覆盖 |
| 分布式、高可用、异地容灾 | 3.7、3.10、3.11、3.14 | 已覆盖；需转化到密钥一致性场景 |
| 数据治理、多租户 | 第六章 6.14、6.17 | 已覆盖基础，补充 SaaS 隔离实践 |
| SDK、服务切片 | 3.17、3.14 新增内容 | 已补充通用工程化知识 |
| 密钥管理/KMS/HSM/PKI | 本章 10.2 | 领域核心，原书缺失 |
| 国密与密评 | 本章 10.4 | 领域核心，原书缺失 |
| 量子网络、QKD、密钥调度 | 本章 10.4 | 领域核心，原书缺失 |

面试权重不应按关键词数量判断。Java 是入场券；KMS 的授权模型、密钥层级和审计闭环决定能否胜任；国密和密评决定合规交付能力；量子方向再考察密钥供给受限时的网络调度思路。
