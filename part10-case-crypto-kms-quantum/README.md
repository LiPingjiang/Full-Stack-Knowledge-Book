# 第十章 · 案例研究：密码基础设施与量子网络密钥管理

> 以 KMS、CMSP、KAAS、量子网络岗位为案例，验证全书在密码安全基础设施方向的覆盖度。

本章沿用第九章的方法：拆 JD → 映射已有知识 → 区分通用能力和领域核心 → 建立面试准备路径。Java、分布式、高并发、多租户和 SDK 工程化是实现手段；密钥生命周期、国密合规、HSM 和量子密钥调度才是岗位差异化能力。
